# Практическое задание 7

```text
Task.Run, 4 части, 10 000 000 элементов: 151 мс, результат совпал с последовательным
Цепочка из 4 задач: 579 мс, завершилась успешно
Исключения: обработано 4
Отмена: да, за 35 мс, таймаут тоже сработал
10 000 маленьких задач: Task.Run 5 мс, новые Thread 354 мс, ускорение 70.80x
Проблемы: Нет
```

`Task.Run` берёт поток из пула. `new Thread` каждый раз создаёт поток операционной системы, поэтому на коротких задачах TPL намного дешевле.
